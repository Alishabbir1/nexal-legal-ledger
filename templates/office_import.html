Supported CSV formats & column names

The importer recognises most UK bank CSV export formats automatically.

Column type Accepted names
Date * Date, Transaction Date, Value Date, Posted Date, Booking Date
Amount * Single column: Amount, Value, Sum
Separate: Debit / Credit, Money Out / Money In, Paid Out / Paid In, Withdrawal / Deposit
Description Description, Narrative, Details, Particulars, Memo, Payee, Counter Party
Reference Reference, Ref, Payment Reference, Cheque Number
Balance Balance, Running Balance, Account Balance, Closing Balance

Date formats accepted: DD/MM/YYYY, YYYY-MM-DD, DD-MM-YYYY, DD.MM.YYYY, DD MMM YYYY.
